# 轻益点

轻益点是瘦益斐浅面向用户端打造的体重与代谢健康管理 APP/小程序。项目基于 Vue 2 与 uni-app，围绕 AKK 菌产品服务、健康自测、AI 健康顾问、顾问随访、健康档案和打卡趋势，构建“产品 + 数据 + 服务”的全周期健康管理体验。

## 一、账号体系

应用保留登录、注册、找回密码、账号资料和安全设置能力，用于保护用户的健康档案、测评结果、预约记录和 AI 对话历史。后续健康数据需要在用户授权下采集、存储和使用。

## 二、健康自测

健康自测用于收集 BMI、体重目标、腰围、体脂、饮食、运动、睡眠、情绪和基础健康情况。系统会基于结果给出风险等级、服务层级建议和后续管理路径，帮助用户从“先建档”进入“持续跟踪”。

## 三、AI 健康顾问

AI 健康顾问用于回答产品使用、健康打卡、饮食运动、睡眠情绪和随访准备等问题。AI 输出仅作健康管理参考，不能替代医生诊断；涉及疾病、用药、严重不适时，应提示用户咨询医生或线下就医。

## 四、科普内容

科普模块围绕科学减重、AKK 菌、肠道微生态、饮食运动、睡眠情绪和产品使用指南展开，帮助用户理解轻益点的科学依据和长期管理方法。

## 五、顾问随访

顾问随访模块支持用户预约健康顾问、营养师或线下服务点，形成“自测 - 建议 - 咨询 - 随访”的基础闭环。后续可扩展医院、社区、企业渠道。

## 六、个人中心

个人中心用于管理账号、安全设置、隐私授权、预约记录、帮助反馈和关于我们。后续将加入健康档案、打卡记录、趋势报告、积分/优惠券和会员权益。
